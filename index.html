Conecta tu portafolio con GitHub

Cada documento que subas aquí se guarda directamente como un commit en tu repositorio. Como ya tienes GitHub Pages activo, el sitio se redespliega solo.

¿Cómo genero el token? Es la única forma de que una app pueda escribir en tu repositorio en tu nombre.
  1. Ve a GitHub → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Crea uno nuevo, límítalo solo al repositorio estadistica-espacial-portfolio.
  3. En permisos, activa Contents: Read and write.
  4. Copia el token aquí. Nunca se envía a ningún servidor más que a api.github.com, directo desde tu navegador.
Directo: github.com/settings/personal-access-tokens/new ↗
